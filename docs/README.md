## Как устроена папка функционала
- **context.md** — зачем он, важность для ключевых воркфлоу, реальные связи (что даёт / что берёт),
  возможные будущие связи, моё понимание и риски, открытые вопросы, статус.
- **tech.md** — техническая документация: сущности, правила/инварианты, интеграции, API, экраны, тесты, где в коде.
- **user.md** — пользовательская документация по ролям: что можно делать и как.

## Шкала важности
- **P0** — без этого нет продаж / нельзя запуститься (блокирует WF-1…WF-4).
- **P1** — нужно к первому запуску, но есть временный обходной путь.
- **P2** — после запуска (этапы 2–3).
- **P3** — бэклог.

## Статусы
`идея` → `спроектировано` → `в разработке` → `на тесте` → `в проде`.
На 2026-10-19 все функционалы в статусе «спроектировано» (кода нет), user.md — черновики того, как это БУДЕТ работать.

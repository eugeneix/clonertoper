# ТЗ для дизайнера: страницы и поля

Версия 0.1 (2026-10-19). Черновик до утверждения пользователем.
Пункты с ⚠️ зависят от открытых вопросов (docs/OPEN-QUESTIONS.md) — могут измениться.

## Общие требования
- Адаптив: **десктоп 1440, планшет 768, мобильный 375**. Мобильные версии обязательны для всех страниц сайта и ЛК (большая часть трафика с телефонов).
- Для каждой страницы нужны состояния: загрузка, пусто («ничего не найдено»), ошибка.
- Формы: обычное поле, фокус, ошибка с текстом, заблокированное; кнопки: основная, второстепенная, текстовая, загрузка, неактивная.
- Цены всегда «за человека», формат `12 500 ₽`. Старая цена — зачёркнутая рядом.
- Все формы с персональными данными — галочка согласия на обработку ПД (ссылка на политику).
- Дизайн отдавать в Figma, компонентами (UI-кит), с переменными цветов/шрифтов.

# Часть 1. Сайт

## 1.1 Шапка (на всех страницах)
- Логотип → главная.
- Меню: Туры по России (выпадающее: категории/направления и подборки — управляется из админки), Речные круизы, Корпоративные туры, Аренда автобусов, Агентствам, Отзывы, О компании, Контакты.
- Телефон, часы работы («в чате 08:00–22:00»), ссылка на MAX.
- Поиск по турам (строка с подсказками: туры, направления).
- Кнопка «Войти» / иконка ЛК с именем, если вошёл.
- Мобильная: бургер-меню, телефон, поиск, ЛК.

## 1.2 Подвал (на всех страницах)
- Меню: О компании, Контакты, Отзывы, Вакансии, Правовая информация, Как оплатить, Агентствам.
- Контакты: телефон, почта, адрес.
- Соцсети: ВКонтакте, Дзен, MAX.
- Подписка на рассылку: e-mail + 2 галочки согласия (ПД, рассылка) + кнопка.
- Юр. информация: ООО «Туроператор Русь», реестровый номер туроператора, «сайт не является публичной офертой».
- Логотипы платёжных систем.

## 1.3 Плавающие элементы
- Виджет чата (кнопка в углу → окно чата, см. 1.17).
- Плашка согласия на cookie (текст, «Принять», ссылка на политику).

## 1.4 Главная (собирается в конструкторе)
Главная состоит из блоков; контент-менеджер включает, выключает и меняет порядок. Нужно нарисовать каждый тип блока:
| Блок | Поля |
|---|---|
| Баннер-слайдер | картинка десктоп/мобильная, заголовок, подзаголовок, текст кнопки, ссылка; точки/стрелки переключения |
| Строка поиска | направление/тур, даты (с–по), город отправления, кнопка «Найти» |
| Плитки категорий | картинка, название, ссылка (кол-во туров — опционально); 4–8 плиток |
| Подборка туров | заголовок, ссылка «Смотреть все», 4–8 карточек тура (карусель на мобильном) |
| Промо-баннер в середине | картинка десктоп/мобильная, ссылка |
| Преимущества | иконка, заголовок, текст × 3–6 |
| Отзывы | средняя оценка, 3–6 отзывов (имя, дата, тур, оценка, текст коротко, фото), ссылка на все |
| Другие продукты | плитки «Речные круизы», «Аренда автобусов», «Корпоративные туры» |
| Текстовый блок | заголовок, текст (SEO) |

## 1.5 Карточка тура в списке (компонент)
- Фото (1, или слайдер 3–5 при наведении — на усмотрение).
- Бейджи (0–3): ручные («Хит», «Скидка 10%», «Новинка») и авто («Осталось 2 места»). Цвет задаётся в админке.
- Название (маршрут), длительность («4 дня»), транспорт (иконка автобуса / «любой транспорт» / без иконки).
- Город отправления.
- 3–4 хайлайта (пункты программы).
- Ближайшие даты (2–3 чипа) + «ещё N дат».
- Цена «от» за человека, старая цена при скидке.
- Рейтинг (звёзды + кол-во отзывов) — если есть.
- Кнопки: «Подробнее», «Заказать».
Варианты: горизонтальная (каталог, десктоп) и вертикальная (подборки, мобильный).

## 1.6 Каталог: категория / направление / подборка
- Хлебные крошки.
- H1, короткое описание вверху (SEO-текст, сворачиваемый).
- Слот баннера (опционально).
- Фильтры: даты (с–по), длительность (1 день / 2–3 / 4–7 / 8+), город отправления, тип тура (многодневный, однодневный, выходного дня, фестиваль, праздничный), транспорт (автобус / без транспорта), цена (от–до). На мобильном — кнопка «Фильтры» → шторка.
- Сортировка: по популярности, по цене, по дате.
- Счётчик «Найдено N туров».
- Список карточек, «Показать ещё» + нумерация страниц.
- SEO-текст внизу.

## 1.7 Страница тура
- Хлебные крошки.
- Галерея (большое фото + превью, полноэкранный просмотр).
- Название, бейджи, рейтинг и ссылка на отзывы.
- Ключевые параметры: длительность, даты (ближайшая), город отправления, транспорт, тип тура.
- Цена «от» за человека; **липкий блок бронирования** (справа на десктопе, снизу на мобильном): выбор даты, цена, «Забронировать», «Задать вопрос» (быстрая заявка).
- Разделы (якорное меню или вкладки):
  - Описание.
  - Программа по дням: «День N», заголовок, текст, фото (опционально), раскрывающиеся.
  - Что входит / не входит в стоимость (два списка).
  - Даты и цены: таблица — дата начала–окончания, дни недели, осталось мест, цена от, кнопка «Выбрать». Отметка праздничных дат.
  - Проживание: отели — фото, название, звёзды, описание, типы номеров.
  - Точки посадки: адрес, время, доплата (если есть).
  - Доп. услуги: название, описание, цена.
  - Условия оплаты: схема (например «30% при бронировании, остаток за 30 дней до начала»).
  - Полезная информация / памятка (текст, файлы).
  - Отзывы о туре (3–5 + «Все отзывы»).
  - Похожие туры (карусель карточек).
- Модальное окно «Задать вопрос / быстрая заявка»: имя, телефон, комментарий, согласие.

## 1.8 Мастер бронирования (пакет 1, самое важное)
Пошагово; на десктопе справа постоянная **сводка заказа**, на мобильном — свёрнутая панель снизу «Итого: … ▲».
Шаги показываются только если применимы (нет автобуса → нет шага мест; однодневный → нет размещения).

**Шаг 1. Дата и туристы**
- Дата выезда (если не выбрана) — список/календарь с ценой и остатком мест.
- Взрослые (− N +), дети (− N +) → для каждого ребёнка выбор возраста.

**Шаг 2. Размещение**
- Отель (если несколько): карточка — фото, название, звёзды, доплата.
- Тип номера: SGL / DBL / TWIN / TRPL — вместимость, цена, остаток номеров.
- Распределение туристов по номерам (если номеров несколько).
- Доп. место (галочка, цена).
- Одиночке: «Доплатить за одноместное» или «Ищу соседа» (⚠️ Q-18 — как отображается цена при подселении).

**Шаг 3. Точка посадки**
- Список: адрес, время, доплата/скидка; выбор радио-кнопкой.

**Шаг 4. Места в автобусе**
- Схема салона: ряды, места с номерами, проход, водитель, двери, туалет, место гида.
- Состояния места: свободно / выбрано мной / занято / служебное (гид) / недоступно. Легенда.
- Если автобусов несколько — переключатель «Автобус 1 / Автобус 2».
- Список туристов с назначенными местами («Турист 1 — место 12»), клик по туристу → выбрать его место.
- Таймер «Места закреплены за вами ещё 14:32».
- Мобильная версия схемы: масштабирование/прокрутка, крупные места для пальца.
- ⚠️ Q-20: если цена мест различается — показ цены на месте.

**Шаг 5. Доп. услуги**
- Список: название, описание, цена, галочка или количество.

**Шаг 6. Данные туристов**
- Для каждого: фамилия, имя, отчество, дата рождения, документ (тип: паспорт РФ / свидетельство о рождении / загранпаспорт; серия и номер), телефон (для главного обязательно), e-mail главного туриста.
- «Выбрать из сохранённых туристов» (если вошёл).
- ⚠️ Q-30: какие поля документа обязательны.
- Комментарий к заказу.

**Шаг 7. Подтверждение и оплата**
- Выбор: «Внести предоплату 30% — 15 000 ₽, остаток до 12.05» / «Оплатить 100%» / «Оставить заявку без оплаты» (тексты и проценты зависят от тура).
- Если не вошёл — вход по телефону прямо здесь (см. 1.9).
- Галочки: согласие с договором, согласие на обработку ПД.
- Кнопка «Оплатить» / «Отправить заявку».

**Сводка заказа (на всех шагах):** фото и название тура, даты, туристы, размещение, точка посадки, места, доп. услуги, расшифровка цены построчно (взрослые × цена, дети со скидкой, доплаты, услуги, скидки), итого.

**Результат:**
- Успех оплаты: номер заказа, сумма оплачено/осталось, срок доплаты, «Документы придут на почту», кнопка «В личный кабинет».
- Заявка без оплаты: номер, «Менеджер свяжется в течение …», кнопка «Оплатить сейчас».
- Ошибка оплаты: причина, «Попробовать снова», «Связаться с нами».
- Место заняли, пока выбирали: сообщение и возврат на схему.

## 1.9 Вход (модальное окно и отдельная страница `/lk/`)
- Шаг 1: телефон; ссылка «Войти по почте».
- Шаг 2: выбор «Код в SMS» / «Звонок (код — последние 4 цифры номера)».
- Шаг 3: поле кода (4–6 ячеек), таймер «Отправить снова через 0:59», «Изменить номер».
- Вариант по почте: e-mail → код → ввод.
- Согласие на обработку ПД.
- Ошибки: неверный код, превышен лимит попыток.

## 1.10 Отзывы `/feedback/`
- Средняя оценка, количество, распределение по звёздам.
- Фильтр по туру/направлению, сортировка (новые, с фото, высокая/низкая оценка).
- Отзыв: имя, дата, тур (ссылка), оценка, текст (с «Читать полностью»), фото (галерея), ответ компании (выделенный блок).
- «Оставить отзыв» → ЛК (отзыв можно оставить только по оплаченному заказу — текст-пояснение).

## 1.11 Речные круизы `/rechnye-kruizy/`
**Список:** фильтры — даты, город отправления, длительность, теплоход, цена; карточка круиза — фото теплохода, маршрут (города), даты, кол-во дней, теплоход, цена от, «Подробнее». ⚠️ Q-21/Q-31: показывать ли круизную компанию.
**Страница круиза:** галерея, маршрут по дням (город, прибытие, отправление, стоянка), информация о теплоходе (ссылка), категории кают (фото, описание, мест в каюте, цена от, «доступно/нет»), что входит, форма заявки.
**Страница теплохода:** галерея, описание, палубы/схема (если есть в API), услуги на борту, список ближайших круизов.
**Форма заявки на круиз:** круиз (подставлен), категория каюты, взрослые, дети, имя, телефон, e-mail, комментарий, согласие. Подпись «Цены обновляются ежедневно, менеджер подтвердит наличие».

## 1.12 Аренда автобусов `/arenda-avtobusov/`
- Вводный блок (текст, преимущества).
- Карточки автобусов: фото, название/модель, мест, удобства (иконки: кондиционер, туалет, ТВ, USB…), «Оставить заявку».
- Страница автобуса (опционально — или раскрытие карточки): галерея, характеристики.
- Форма заявки: автобус (подставлен или «любой»), дата и время подачи, дата окончания, откуда, куда (маршрут), кол-во пассажиров, имя, телефон, e-mail, комментарий, согласие.

## 1.13 Корпоративные туры `/korporativnye-tury/`
- Лендинг из блоков конструктора (баннер, преимущества, примеры программ/туров, отзывы компаний, текст).
- Форма заявки: компания, ИНН (необязательно), контактное лицо, телефон, e-mail, кол-во человек, желаемые даты/период, направление или тур, бюджет на человека (необязательно), пожелания, согласие.

## 1.14 Агентствам
- Информация: условия сотрудничества, преимущества, контакты отдела.
- Кнопка «Войти в кабинет агента».
- Форма заявки на регистрацию: название агентства, юр. название, ИНН, КПП, ОГРН, юр. адрес, город, контактное лицо, телефон, e-mail, сайт, комментарий, согласие. После отправки — «Заявка принята, мы пришлём логин и пароль».

## 1.15 Статические страницы
О компании, Контакты (адрес, карта, телефоны, почта, часы работы, реквизиты), Как оплатить, Правовая информация (список документов), Политика обработки ПД, Вакансии, 404 (с поиском и популярными турами). Общий шаблон текстовой страницы: хлебные крошки, H1, текст, изображения, таблицы, файлы.

## 1.16 Блог (этап 3, можно позже)
Список статей (обложка, заголовок, дата, анонс, теги), статья (обложка, текст, изображения, связанные туры внизу).

## 1.17 Чат (этап 3)
- Окно: заголовок «Чат с менеджером», сообщения (клиент / менеджер с именем и аватаром), поле ввода, вложение, отправка.
- Не вошёл: имя и телефон перед первым сообщением.
- Нерабочее время: «Мы ответим с 08:00» + форма заявки.
- Ссылка «Написать в MAX».

## 1.18 Письма (этап 1, простой шаблон)
Один фирменный шаблон письма: шапка с логотипом, заголовок, текст, кнопка, подвал с контактами. Используется для: кода входа, брони, оплаты, напоминания о доплате, документов, просьбы об отзыве.

# Часть 2. Личный кабинет туриста `/lk/`
Меню: Мои заказы, Мои туристы, Мои отзывы, Чат, Профиль, Выйти.

## 2.1 Мои заказы (список)
Карточка: номер заказа, тур (фото, название), даты, туристов, статус (новая / в работе / забронирован / оплачен частично / оплачен / завершён / аннулирован — цветом), сумма, оплачено, осталось, ближайший платёж (дата, сумма), кнопка «Доплатить». Табы: Активные / Завершённые.

## 2.2 Заказ (детально)
- Шапка: номер, статус, тур (ссылка), даты.
- Туристы: ФИО, место в автобусе, номер/отель.
- Посадка: точка, адрес, время.
- График платежей: дата, сумма, статус (оплачен / ожидается / просрочен); кнопка «Оплатить».
- Платежи и чеки: дата, сумма, способ, ссылка на чек.
- Документы: тип, дата, «Скачать PDF».
- Ваш менеджер: имя, телефон, «Написать в чат».
- «Оставить отзыв» (если заказ оплачен и отзыва нет).

## 2.3 Мои туристы
Список (ФИО, дата рождения), добавить/изменить/удалить. Форма: ФИО, дата рождения, документ (тип, серия, номер), телефон.

## 2.4 Мои отзывы
Список: тур, дата, оценка, статус (на модерации / опубликован / отклонён), ответ компании.
Форма отзыва: оценка (5 звёзд), текст, фото (до 10, перетаскивание, превью, удаление), кнопка «Отправить на модерацию».

## 2.5 Профиль
Имя, телефон (смена через код), e-mail (смена через код), согласие на рассылку.

# Часть 3. Панели сотрудников `/staff` и агентов `/agent`
**Делаются на готовой системе интерфейсов (Filament). Отдельный дизайн НЕ нужен** — только логотип, основной цвет, фавикон. Ниже — что будет на экранах, для понимания объёма и проверки.
Экраны со знаком ✏️ — нестандартные, дизайнер может предложить вид (необязательно).

## 3.1 Общее
- Вход (логин, пароль).
- Боковое меню по разделам (видно только разрешённое ролью), колокольчик уведомлений, профиль.

## 3.2 Дашборд «Мои задачи» ✏️
Новые заявки (кол-во, список), ждут ответа, неоплаченные брони, просроченные доплаты, доплаты на этой неделе, мои показатели (заявок, продаж, конверсия за месяц).

## 3.3 Заказы
- Список: номер, дата создания, клиент, телефон, тур/продукт, дата выезда, туристов, сумма, оплачено, долг, статус, канал, менеджер, агентство. Фильтры по всем полям, поиск по номеру/телефону/ФИО.
- Карточка заказа ✏️, вкладки: Состав (позиции, расшифровка цены, ручная корректировка с причиной) · Туристы (данные, место, номер) · Места (схема рейса) · Оплаты (график, платежи, «Ссылка на оплату», «Внести оплату», «Возврат», «Штраф») · Документы (сформировать, загрузить PDF, версии, отправить) · Коммуникации (звонки с записями, чат) · История (журнал).
- Действия: назначить менеджера, сменить статус, перенести на другой выезд/тур, аннулировать (причина, штраф, сумма возврата).
- Новая бронь: тот же мастер, что на сайте, + ручные цены.

## 3.4 Туры
Список: фото, название, тип, длительность, ближайший выезд, вес, статус, бейджи.
Форма тура, вкладки: Основное (название, адрес страницы, тип, длительность, город отправления, транспорт есть/нет, категории, теги, вес, статус, партнёрский/партнёр) · Описание и программа (по дням) · Фото · Что входит / не входит · Цены (правила, детские скидки, доплаты, наценки) · Доп. услуги · Оплата (схема) · Мин. группа и шаблон себестоимости · Бейджи · SEO · Отзывы.

## 3.5 Выезды
Список по туру/датам: даты, статус, мест всего/занято/свободно, номеров, туристов, выручка, себестоимость план, маржа, флаг «ниже безубыточности».
Форма: даты, праздничный (галочка), точки посадки (время, доплата), рейсы, размещение (отель, тип номера, квота), цены выезда, себестоимость план/факт. Печать: посадочная ведомость, список группы.

## 3.6 Транспорт
- Схемы салонов: список; **конструктор схемы ✏️** (сетка рядов, тип клетки: место / проход / дверь / водитель / гид / туалет / пусто, нумерация).
- Рейсы: схема, автобус, привязанные выезды; **схема рейса ✏️** (состояния мест, кто сидит, оплачено ли; пересадить, заблокировать, снять бронь).

## 3.7 Справочники
Отели (название, город, звёзды, описание, фото), типы номеров, точки посадки (адрес, координаты), города, категории туров, схемы оплаты, производственный календарь.

## 3.8 Продукты-заявки
Круизы (список из синхронизации только для чтения, статус синхронизации, ошибки), автобусы аренды (фото, название, мест, удобства, порядок), корпоративные заявки (воронка: новая → КП → договор → счёт → закрыта).

## 3.9 Продажи
Очереди распределения (продукт, режим, участники, веса), рейтинг менеджеров (заявки, продажи, конверсия, выручка, скорость ответа), агентства (реквизиты, договор, комиссия, статус) и заявки агентств, чаты ✏️ (список диалогов сайт/MAX + окно диалога), звонки.

## 3.10 Контент
Главная (конструктор блоков 1.4), страницы, категории, подборки (вручную / по правилу), редиректы, блог.

## 3.11 Промо
Баннеры (картинки десктоп/мобильная, ссылка, место показа, даты, приоритет, показы/клики), бейджи (текст, цвет, иконка) и их назначение турам на период.

## 3.12 Отзывы
Модерация: тур, клиент, заказ, оценка, текст, фото, статус, ответ компании.

## 3.13 Бухгалтерия и отчёты
Реестр оплат, сверка PayKeeper, должники/просрочки, возвраты и штрафы, начисления агентам и партнёрам, экспорт в Excel. Отчёты: продажи по продуктам/периодам, загрузка выездов, маржа план/факт, менеджеры, агентства, источники заявок.

## 3.14 Настройки
Пользователи (ФИО, логин, телефон, роли, направления, активен), роли (матрица галочек), шаблоны документов (версии, загрузка Word, предпросмотр), уведомления (событие, канал, текст), журнал действий.

## 3.15 Панель агента `/agent`
Дашборд (мои заказы, комиссия за месяц), поиск туров (как каталог), бронирование (мастер), мои заказы (список и карточка без внутренних полей), комиссии и взаиморасчёты, профиль агентства. ⚠️ Состав уточнится после разговора про агентов (Q-02, Q-03).

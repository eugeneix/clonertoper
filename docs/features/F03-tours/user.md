# F03 — пользовательская документация (черновик)

## Менеджер продукта / контент-менеджер
1. «Туры» → «Создать»: название, тип, длительность, есть ли транспорт, программа по дням, фото, категории, вес (чем выше, тем выше в выдаче), схема оплаты, минимальная группа.
2. Добавьте доп. услуги со своими ценами.
3. Вкладка «Выезды» → «Добавить выезд»: даты, точки посадки и время, рейсы (автобусы) или квоту мест, размещение.
4. Кнопка «Копировать» — создать похожий тур или выезд быстро.
5. «Опубликовать» — тур появится на сайте.
6. Если группа не набирается — откройте выезд и перенесите заявки на другой выезд (F09).

## Турист
На странице тура: программа, даты выездов со свободными местами и ценой «от».

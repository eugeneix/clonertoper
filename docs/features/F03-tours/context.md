# F03 Туры и выезды — контекст
**Статус:** спроектировано · **Важность:** P0 · **Воркфлоу:** WF-1, WF-3 · **Этап:** 1

## Зачем
Основной продукт компании. Тур — карточка (программа, фото, описание, правила). Выезд — конкретные даты с квотой мест, ценами, размещением, транспортом.

## Важность для ключевых воркфлоу
Без туров нет каталога, заказов, денег. 780 туров в каталоге.

|---|---|

| F05 Транспорт | выезд имеет рейсы (автобусы со схемами) или не имеет транспорта (A-09) |

## Возможные связи
- Отзывы (F27) на тур, средняя оценка на карточке.
- Перенос заявок между выездами при недоборе группы (D-35) — затрагивает F09, F10, F05, F04.

## Как я это понимаю
- Типы: многодневные, однодневные, выходного дня, фестивали, праздничные; с автобусом и без.
- Доп. услуги, наценки, скидки — свои для каждого тура.
- **Минимальная группа**: если не набралась — предлагают замену (перенос на другой выезд/тур).
- Риск: если A-08 (стекование рейсов) верно, то места живут на рейсе, а не на выезде; квота выезда = сумма мест рейсов, привязанных к выезду. Это главный вопрос модели (Q-06).
- Нужно копирование тура и выезда (у туроператора много похожих выездов).

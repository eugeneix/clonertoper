# F22 Корпоратив — контекст
**Статус:** спроектировано · **Важность:** P1 · **Воркфлоу:** WF-6 · **Этап:** 1

## Зачем
Отдельный канал/воронка поверх всех продуктов (свои и чужие туры, всё). Процесс: заявка → КП → договор с юрлицом → счёт → акт (ответ 23). Кабинет клиента, закрывающие документы, онлайн-заказ — не нужны сейчас.

## Реальные связи
F09 (product_line=corporate, позиции любых типов), F14 (очередь «корпоратив»), F11 (КП, договор, счёт, акт), F10 (безнал вручную), F08 (`/korporativnye-tury/`).

## Как я это понимаю
- Главное сейчас — получать заявки и вести их отдельно в админке. КП/договор/счёт формируются шаблонами F11.

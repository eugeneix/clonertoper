# F08 SEO и URL — контекст
**Статус:** спроектировано · **Важность:** P0 · **Воркфлоу:** WF-1, WF-7 · **Этап:** 1

## Зачем
Сохранить поисковый трафик (≈60% вместе с рекламой) при переезде: те же URL или 301, мета-теги, sitemap, robots, микроразметка, скорость.

## Важность
Потеря позиций = потеря денег сразу после запуска. Высший риск переезда.

## Реальные связи
| С чем | Что |
|---|---|
| F32 Перенос | legacy URL всех актуальных туров и категорий → новая карта |
| F03, F07 | slug туров/категорий/подборок; смена slug → 301 |
| F28 | мета главной |
| F30 Блог | статьи — SEO-трафик |
| F29 | баннеры не должны ломать LCP |

## Как я это понимаю
- Текущие паттерны: `/tury/poekhali/<slug>-<id>/`, `/tury/<category>/`, со слешем на конце. Сохраняем этот формат как основной, чтобы не было редиректов вообще.
- Неактуальные туры не переносим (D-21) → для их URL нужен 301 на категорию, а не 404, иначе потеря ссылочного веса.
- Нужен доступ к Метрике и Вебмастеру (пользователь: есть) — для проверки после запуска.

# F12 ЛК туриста — контекст
**Статус:** спроектировано · **Важность:** P0 · **Воркфлоу:** WF-1, WF-8 · **Этап:** 1

## Зачем
Личный кабинет: заказы, документы, оплата/доплата онлайн, сохранённые данные туристов, отзывы с фото и оценкой, (позже) бонусы, чат с менеджером.

## Важность
Доплаты по графику идут через ЛК — это существенная часть денег. Без ЛК менеджеры вручную рассылают ссылки.

## Реальные связи
| С чем | Что |
|---|---|
| F01 | вход по SMS/звонку/почте |
| F09 | список заказов |
| F10 | доплата, график, чеки |
| F11 | документы |
| F27 | отзывы после оплаченной поездки |
| F19 | чат с менеджером |
| F31 | бонусы (бэклог) |
| F17 | уведомления о событиях |

## Как я это понимаю
- «Сохранённые туристы» = записная книжка с паспортными данными для повторных броней (ответ 27 — «всё верно»). Чувствительные данные → шифрование, доступ только владельцу.
- Текущий ЛК на `/lk/` — сохранить адрес.

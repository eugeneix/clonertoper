# F12 — пользовательская документация (черновик)

## Турист
- **Мои заказы** — статус, состав, места, график платежей, кнопка «Доплатить».
- **Документы** — договор, ваучер, памятка, чеки.
- **Мои туристы** — сохраните данные близких, чтобы не вводить их заново.
- **Отзывы** — после оплаченной поездки поставьте оценку, напишите отзыв, добавьте фото.
- **Чат** — напишите своему менеджеру.

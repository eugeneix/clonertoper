# F24 Себестоимость и выгода — контекст
**Статус:** спроектировано · **Важность:** P1 · **Воркфлоу:** WF-3 · **Этап:** 2

## Зачем
Расчёт себестоимости тура: план при создании и факт по итогам выезда (D-35); постоянные расходы группы (автобус, гид, водитель) и переменные на человека (отель, входные билеты, питание); точка безубыточности, минимальная группа, маржа план/факт.

## Реальные связи
F03 (выезд, мин. группа), F05 (стоимость рейса/автобуса), F04 (стоимость номеров), F06/F09 (выручка), F25/F26 (отчёты маржи), F02 (право видеть себестоимость — чувствительно).

## Как я это понимаю
- Шаблон расходов на уровне тура → копируется в каждый выезд как план → после поездки вносится факт.
- Стекованный рейс (A-08) — стоимость автобуса нужно делить между выездами (пропорционально местам?) ⚠️ спросить.
- Недобор группы → система подсвечивает выезды ниже точки безубыточности, чтобы вовремя предложить замену.

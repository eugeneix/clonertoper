# F24 — пользовательская документация (черновик)
## Менеджер продукта
В туре задайте шаблон расходов. В каждом выезде вкладка «Себестоимость»: плановые расходы, сколько туристов нужно для безубыточности, текущая маржа. После поездки внесите фактические расходы — увидите итоговую выгоду.
## Руководитель
Отчёт «Маржа по выездам»: план против факта.

# F02 — пользовательская документация (черновик)

## Администратор
1. «Настройки → Роли» → «Создать роль», например «Менеджер круизов».
2. Отметьте галочками, что разрешено: видеть заявки (свои / направления / все), редактировать туры, вносить оплаты, видеть себестоимость и т.д.
3. «Пользователи» → выберите сотрудника → назначьте одну или несколько ролей.
4. Чтобы отключить сезонного сотрудника — кнопка «Заблокировать». Его заявки перейдут другим (см. F14).
Все изменения ролей сохраняются в журнале.

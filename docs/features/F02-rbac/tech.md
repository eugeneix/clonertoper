# F02 — техническая документация
**Статус реализации:** не начато.

## Сущности
spatie/laravel-permission: `permissions`, `roles`, `role_has_permissions`, `model_has_roles`. Права не создаются вручную в БД — объявляются в коде (сидер/реестр), роли собирает админ в интерфейсе.

## Правила
- Имена прав: `<модуль>.<объект>.<действие>[.<область>]`, напр. `sales.orders.view.own`, `finance.cost.view`.
- Каждый Filament-ресурс и API-контроллер проверяет право через Policy.
- Агент никогда не получает staff-права, даже при ошибке назначения (guard `agent` отдельный).
- Суперадмин — единственная роль, обходящая проверки; её нельзя удалить и выдать себе без другого суперадмина.

## Экраны
- Роли: список, создание, матрица галочек по модулям.
- Пользователи: назначение ролей, блокировка.

## Обязательные тесты
Матрица: для каждого ресурса — доступ с правом и отказ без права; агент не видит чужие заказы.

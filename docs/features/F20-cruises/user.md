# F20 — пользовательская документация (черновик)
## Турист
«Речные круизы»: выберите маршрут, даты, теплоход, категорию каюты — оставьте заявку. Менеджер подтвердит наличие и свяжется.
## Менеджер
Заявки на круизы приходят в очередь «Круизы». Забронируйте каюту у круизной компании и отметьте это в заказе.
## Администратор
«Круизы → Синхронизация»: время последнего обновления, ошибки.

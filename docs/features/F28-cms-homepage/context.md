# F28 Конструктор главной — контекст
**Статус:** спроектировано · **Важность:** P1 · **Воркфлоу:** WF-7 · **Этап:** 1 (обязательно, D-27)

## Зачем
Редактор главной страницы без программиста: порядок блоков, плитки категорий со ссылками, подборки туров, баннеры, тексты.

## Реальные связи
F07 (категории, подборки, туры), F29 (баннеры), F08 (мета главной), F20/F21/F22 (ссылки на круизы, аренду, корпоратив).

## Как я это понимаю
- Набор типов блоков фиксирован (разработчик), а наполнение и порядок — контент-менеджер. Так дизайн не ломается.
- Тот же механизм блоков можно потом использовать для посадочных страниц (подборки, праздники).

# F06 Ценообразование — контекст
**Статус:** спроектировано · **Важность:** P0 · **Воркфлоу:** WF-1, WF-2, WF-3 · **Этап:** 1

## Зачем
Расчёт цены заказа: базовая цена за человека, отель/тип номера, доплата SGL, детские скидки, точки посадки, доп. услуги, наценки и скидки тура, ручная корректировка менеджером. Наценка на партнёрские туры.

## Важность
Ошибка в цене = прямые деньги. Цена должна считаться одинаково на витрине, в кабинете менеджера, у агента, в документах.

## Реальные связи
| С чем | Что |
|---|---|
| F03, F04, F05 | источники цен: выезд, размещение, точки посадки |
| F09 Заказы | итоговая цена **фиксируется** в заказе (снимок), изменения тура не меняют старые заказы |
| F10 Платежи | от итоговой суммы считается предоплата по схеме |
| F15 Агенты | комиссия агента от цены (Q-03) |
| F23 Партнёрские | цена партнёра + своя наценка, клиент видит только итог |
| F29 Промо | бейдж «Скидка 10%» может отражать реальную скидку (автобейдж) |
| F24 Себестоимость | маржа = цена − себестоимость |
| F34 Журнал | ручное изменение цены туриста |

## Возможные связи
- F31 Бонусы — списание бонусов как скидка.
- Мультивалютность (D-20): цена в валюте + курс.
- Промокоды (не обсуждались).

## Как я это понимаю
- Детские скидки задаются вручную в каждом туре (ответ 13): правила «возраст от–до на дату начала тура → −X ₽ или −Y%». Возраст считаем на дату начала тура — ⚠️ моё допущение.
- Калькулятор цены — один сервис на бэкенде; фронт только показывает результат.
- Цена «от» на карточке = минимальная взрослая цена среди открытых выездов.

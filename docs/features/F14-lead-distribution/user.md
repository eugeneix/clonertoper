# F14 — пользовательская документация (черновик)

## Руководитель продаж
«Продажи → Очереди»: для каждого продукта выберите, кто принимает заявки, и режим — вручную, по кругу или по рейтингу. «Рейтинг менеджеров»: заявки, продажи, конверсия, скорость ответа.

## Менеджер
Новые заявки приходят вам автоматически с уведомлением. Чем лучше вы доводите заявки до оплаты, тем чаще получаете новые.

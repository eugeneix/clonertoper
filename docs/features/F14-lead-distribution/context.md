# F14 Распределение заявок и рейтинг — контекст
**Статус:** спроектировано · **Важность:** P1 (ручное — P0) · **Воркфлоу:** WF-2 · **Этап:** 1 ручное / 3 авто

## Зачем
Новые заявки распределяются между менеджерами по продуктам (туры, круизы, автобусы, корпоратив). Ведётся рейтинг: кто сколько продал и кто лучше доводит до продажи; лучшие получают заявки чаще (D-16).

## Важность
Скорость первого ответа и качество обработки напрямую влияют на продажи. На старте можно распределять вручную/по кругу.

## Реальные связи

| F17 | уведомление менеджеру |
| F18/F19 | заявки из звонков и чатов тоже распределяются |
| F26 | отчёты по менеджерам |

## Как я это понимаю
- Алгоритм: взвешенный круговой (weighted round-robin) внутри очереди продукта; вес = функция конверсии за период. Новичкам (сезонникам без истории) — базовый вес, иначе они никогда не получат заявок.
- Нужно разделять менеджеров и агентов в рейтинге (агентам заявки не распределяются — ⚠️ предполагаю).
- Блокировка сотрудника → его открытые заявки уходят в перераспределение (A-12).

# F01 — техническая документация
**Статус реализации:** не начато.

## Сущности
- `users` — общий: `type` (client | staff | agent), phone (E.164), email, password_hash (для staff/agent), is_active, agency_id.
- `login_codes` — hash кода, канал (sms | call | email), получатель, expires_at (5 мин), attempts, ip.
- Сессии Laravel (staff/agent — Filament), токены Sanctum для Next.js витрины/ЛК.

## Правила
- Код: 4–6 цифр, живёт 5 мин, максимум 5 попыток, повторная отправка не чаще 60 с, лимиты по номеру и IP в сутки.
- При звонке-коде sms.ru возвращает код (последние цифры номера) — сохраняем его hash.
- Вход клиента создаёт пользователя, если его нет; привязывает гостевые заказы с тем же телефоном/почтой.
- Заблокированный пользователь (`is_active=false`) не может войти, активные сессии сбрасываются.

## Интеграции
- sms.ru: отправка SMS и звонок-код (env `SMSRU_API_ID`).
- Почта: SMTP или транзакционный сервис (env `MAIL_*`).

## API (черновик)
- `POST /api/auth/code` {channel, phone|email} → отправка.
- `POST /api/auth/verify` {phone|email, code} → токен.
- `POST /api/auth/logout`.

## Обязательные тесты
Истечение кода, лимит попыток, лимит отправок, склейка гостевых заказов, блокировка сотрудника.

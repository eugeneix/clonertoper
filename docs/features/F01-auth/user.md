# F01 — пользовательская документация (черновик)

## Турист
1. Нажмите «Войти», введите телефон.
2. Выберите: получить код в SMS или принять звонок (код — последние цифры номера, с которого звонят).
3. Введите код. Пароль не нужен.
4. Нет доступа к телефону — войдите по коду на почту.
Все ваши заказы, оформленные на этот телефон или почту, появятся в личном кабинете.

## Сотрудник
Вход на `/staff` по логину и паролю, который выдаёт администратор. Если учётку заблокировали — обратитесь к руководителю.

## Агент
Подайте запрос на странице «Агентствам». После проверки администратор выдаст логин и пароль для входа на `/agent`.

## Администратор
Создание сотрудников, выдача и блокировка доступа — в разделе «Пользователи» (см. F02).

# F09 — пользовательская документация (черновик)

## Турист
После оформления у заказа есть номер; статус, состав, оплаты и документы — в личном кабинете.

## Менеджер / агент
Карточка заказа: туристы, места, номера, цена с расшифровкой, график платежей, документы, история, чат и звонки.
- «Перенести» — на другой выезд или тур (оплаты сохраняются).
- «Аннулировать» — укажите причину, штраф и сумму к возврату вручную.
- Заявку из звонка/чата дополните до брони: выберите тур, даты, места.

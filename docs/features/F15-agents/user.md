# F15 — пользовательская документация (черновик)

## Агентство
1. На странице «Агентствам» заполните заявку: название, реквизиты, контакты.
2. После проверки получите логин и пароль.
3. В кабинете `/agent` бронируйте туры для клиентов, видите цену и свою комиссию, все свои заказы.

## Администратор
«Агентства → Заявки»: проверьте, одобрите, выдайте доступ, задайте комиссию.

# F07 — пользовательская документация (черновик)

## Турист
Выберите направление или подборку, отфильтруйте по датам, длительности, цене, городу отправления. Откройте тур — программа, даты, цены, отзывы, «Заказать тур».

## Контент-менеджер
Категории и подборки — в разделе «Контент». Подборка может быть ручной (выбрали туры) или по правилу (например, все туры с датами 1–8 января). Порядок туров регулируется весом тура.

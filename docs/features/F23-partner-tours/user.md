# F23 — пользовательская документация (черновик)
## Менеджер продукта
Создайте тур как обычно, отметьте «Партнёрский» и выберите партнёра, укажите цену партнёра и наценку. На сайте клиент видит только итоговую цену, без упоминания партнёра.
## Менеджер продаж
В заказе с партнёрским туром отметьте, что место забронировано у партнёра.

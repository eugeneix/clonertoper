# F04 — пользовательская документация (черновик)

## Турист
При бронировании многодневного тура выберите отель (если вариантов несколько) и тип номера. Едете один — можно доплатить за одноместный номер или отметить «Ищу соседа»: менеджер подберёт попутчика.

## Менеджер продукта
В выезде, вкладка «Размещение»: добавьте отель, типы номеров и количество номеров (квоту). Система не даст продать больше номеров, чем есть.

## Менеджер продаж
В заказе видно, кто в каком номере. Для «Ищу соседа» — список ожидающих по выезду, объедините двух туристов в один номер.

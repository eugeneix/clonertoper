# F04 Размещение — контекст
**Статус:** спроектировано · **Важность:** P0 · **Воркфлоу:** WF-1, WF-3 · **Этап:** 1

## Зачем
Выбор отеля и типа номера в туре, учёт квот номеров, доплата за одноместное, доп. место, подселение (D-34).

## Важность
Многодневные туры без размещения продать нельзя. Перепродажа номеров = реальные убытки.

## Реальные связи
| С чем | Что |
|---|---|
| F03 Выезды | выезд содержит варианты размещения |
| F06 Цены | цена зависит от отеля и типа размещения; доплата SGL |
| F09 Заказы | туристы распределяются по номерам; резерв квоты |
| F24 Себестоимость | стоимость номеров — расход на человека/номер |
| F11 Документы | лист бронирования/ваучер с отелем |

## Возможные связи
- Рассылка списков проживающих отелю (rooming list).
- Партнёрские туры с отелями партнёра.

## Как я это понимаю
- Квота — в номерах, а продаётся за человека. DBL на 2, TRPL на 3, доп. место — опция номера. Значит, резерв идёт в номерах, а цена считается по людям. Одиночка в DBL без подселения = доплата SGL.
- Подселение: турист-одиночка ставит «ищу соседа», занимает «половину» DBL; менеджер вручную сводит пару (A-10). Пока пары нет — нужно решить, платит ли он SGL. ⚠️ не обсуждалось.
- Однодневные туры без размещения.

# F16 Кабинет оператора — контекст
**Статус:** идея · **Важность:** не определена · **Этап:** не определён

## Зачем
Пользователь: «кабинет оператора — для ведения своих заявок и редактирования туров». Кто такой оператор — не определено (Q-01).

## Варианты
1. **Сотрудник** (менеджер продукта / менеджер продаж) → это просто роль F02 в панели `/staff`. Отдельной разработки нет.
2. **Внешний туроператор**, размещающий свои туры на площадке → отдельный модуль поставщика: свои туры, модерация, свои заявки, взаиморасчёты. Сильно связан с F23 (партнёрские туры) — по сути партнёр, который сам заводит туры вместо менеджера.

## Как я это понимаю
Фраза «редактирование туров + свои заявки» подходит под оба варианта. Если вариант 2 — партнёрские туры (F23) и операторы надо проектировать вместе. Модель туров уже имеет `is_partner/partner_id`, это закладывает вариант 2.

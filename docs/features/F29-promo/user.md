# F29 — пользовательская документация (черновик)
## Маркетолог
- «Промо → Баннеры»: загрузите картинку (для компьютера и телефона), ссылку, место показа и даты — баннер сам включится и выключится.
- «Промо → Бейджи»: создайте бейдж (текст, цвет), назначьте турам на период. «Осталось N мест» и реальные скидки показываются автоматически.

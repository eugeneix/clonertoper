# F11 Документы — контекст
**Статус:** спроектировано · **Важность:** P1 · **Воркфлоу:** WF-1, WF-2, WF-6, WF-8 · **Этап:** 1

## Зачем
Генерация документов по шаблонам (договор о реализации турпродукта, ваучер, лист бронирования, памятка, счёт, акт, КП, посадочная ведомость), редактирование шаблонов в админке, замена документа своим PDF, хранение всех версий.

## Важность
Договор с туристом обязателен по закону. Временный обход — делать документы вручную, но при 150+ заявках это тяжело.

## Реальные связи
| С чем | Что |
|---|---|
| F09 | данные заказа, туристы |
| F10 | суммы, график, реквизиты оплаты |
| F03/F04/F05 | программа, отель, место, точка посадки |
| F12 | турист скачивает документы в ЛК |
| F13 | менеджер формирует, заменяет PDF |
| F22 | КП, договор, счёт, акт для корпоратива |
| F17 | отправка документов на почту |

## Как я это понимаю
- **Главное правило (D-08):** документ, выданный по заказу, неизменяем. Хранится PDF + снимок данных + ссылка на версию шаблона. Правка шаблона влияет только на новые документы. Замена PDF = новая версия, старая в архиве.
- Шаблоны — Word с полями `{order.number}`, `{#tourists}…{/tourists}` — привычно сотрудникам; редактирование в админке = загрузка новой версии шаблона. ⚠️ Если нужен визуальный редактор прямо в браузере — это другой объём (OnlyOffice). Пользователь сказал «правка шаблонов в админке» — начну с загрузки Word + предпросмотра; визуальный редактор — если попросят.
- Электронная подпись — бэклог.

## Решения
D-08.

# F11 — пользовательская документация (черновик)

## Администратор / юрист
«Документы → Шаблоны»: скачайте текущий шаблон Word, внесите правки, загрузите как новую версию, проверьте предпросмотр, сделайте активной. Старые документы в заказах не изменятся. Список полей для подстановки — на странице шаблона.

## Менеджер
В заказе вкладка «Документы»: «Сформировать» (договор, ваучер, счёт…), «Загрузить PDF» — заменить документ своим файлом (старая версия останется в истории), «Отправить клиенту».

## Турист
Все документы по заказу — в личном кабинете, скачать PDF.

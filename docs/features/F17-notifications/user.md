# F17 — пользовательская документация (черновик)

## Администратор
«Настройки → Уведомления»: для каждого события (бронь, оплата, напоминание о доплате…) включите каналы (почта/SMS) и отредактируйте текст. Журнал отправок показывает, дошло ли сообщение.

## Сотрудник
Колокольчик в интерфейсе — новые заявки, оплаты, просрочки.

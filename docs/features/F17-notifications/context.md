# F17 Уведомления — контекст
**Статус:** спроектировано · **Важность:** P0 · **Воркфлоу:** все · **Этап:** 1

## Зачем
SMS и почта клиентам (коды, бронь, оплата, напоминания о доплате, документы, напоминание перед поездкой, просьба об отзыве); уведомления сотрудникам (новая заявка, оплата, просрочка); алерты техподдержке (F33).

## Реальные связи
F01 (коды), F09 (статусы), F10 (оплаты, долги), F11 (документы), F14 (назначение), F27 (просьба об отзыве), F19 (MAX как канал — позже), F33 (алерты).

## Как я это понимаю
- Шаблоны уведомлений редактируются в админке.
- SMS дорогие → по умолчанию почта, SMS — для кодов и критичных напоминаний (настраивается).

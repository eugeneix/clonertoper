# F18 Телефония Манго Офис — контекст
**Статус:** спроектировано · **Важность:** P1 · **Воркфлоу:** WF-2 · **Этап:** 1

## Зачем
Звонок в Манго Офис создаёт заявку (D-17), запись разговора и история звонков в карточке заказа/клиента, звонок из карточки (click-to-call).

## Реальные связи
F09 (создание заявки, привязка к заказу по номеру), F14 (распределение заявки из звонка), F13 (карточка), F26 (аналитика звонков), F01/клиенты (поиск клиента по номеру).

## Как я это понимаю
- Входящий от неизвестного номера → новая заявка «из звонка» в очередь. От известного клиента с открытым заказом → звонок прикрепляется к заказу, новая заявка не создаётся (⚠️ моё допущение).
- Нужен доступ к API Манго (ключ и соль) и настройка вебхуков на наш адрес.

# F25 Бухгалтерия — контекст
**Статус:** спроектировано · **Важность:** P1 · **Воркфлоу:** WF-4 · **Этап:** 2

## Зачем
Реестр всех оплат (онлайн и ручных), сверка с банком/PayKeeper, долги и просрочки, возвраты, выплаты партнёрам и комиссии агентам (ответ 38: «всё нужно»). 1С — позже (Q-14).

## Реальные связи
F10 (источник всех денежных операций), F15 (комиссии), F23 (выплаты партнёрам), F24 (себестоимость), F26 (отчёты), F02 (роль бухгалтера), F34 (журнал ручных операций).

## Как я это понимаю
- Бухгалтер должен видеть всё, но не обязательно править заказы.
- Выгрузки в Excel обязательны с первого дня (бухгалтеры так работают).

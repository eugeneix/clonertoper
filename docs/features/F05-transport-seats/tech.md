# F05 — техническая документация
**Статус реализации:** не начато.

## Сущности
- `bus_layouts`: название, вместимость, `grid` (JSON: ряды × колонки, типы клеток: seat | aisle | door | driver | guide | wc | empty), номера мест.
- `buses` (опционально): госномер, модель, layout по умолчанию.
- `trips`: layout_id, bus_id?, дата/маршрут, статус.
- `departure_trip` (pivot): departure_id, trip_id.
- `seat_states`: trip_id, seat_number, state (free | hold | booked | blocked), order_tourist_id?, hold_expires_at, block_reason (guide | staff | other).
- Уникальный индекс (trip_id, seat_number) — один турист на место.

## Правила
- Выбор места: `SELECT … FOR UPDATE` по строке места; hold на время оформления; при создании заказа hold → booked.
- Истёкшие hold освобождаются фоновой задачей. booked без оплаты НЕ освобождаются (D-10).
- Пересадка — атомарная смена двух мест, запись в журнал (F34).
- Изменение схемы рейса, где уже есть брони, запрещено, если удаляются занятые места.

## Реалтайм
Reverb-канал `trip.{id}.seats` — турист и менеджер видят изменения сразу.

## Экраны
Конструктор схемы (drag-and-drop сетка), схема рейса для менеджера (цвета состояний, клик → пересадить/заблокировать), выбор места на витрине (React-компонент).

## Печать
Посадочная ведомость: точка посадки → время → место → ФИО → телефон. Список группы.

## Обязательные тесты
Гонка за одно место (параллельные транзакции), истечение hold, пересадка, стекованный рейс (2 выезда в одном автобусе), блокировка места гида.

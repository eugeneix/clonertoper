# F05 — пользовательская документация (черновик)

## Турист
На шаге бронирования откройте схему автобуса и выберите места для каждого туриста. Серые места заняты. Место закрепляется за вами на время оформления; после оформления заказа оно ваше.

## Менеджер продукта
1. «Транспорт → Схемы салонов» → «Создать»: нарисуйте сетку, отметьте места, проход, двери, место гида.
2. В выезде добавьте рейс: выберите схему (и автобус). Если на выезд несколько автобусов — добавьте несколько рейсов. Один рейс можно привязать к нескольким выездам.

## Менеджер продаж
Схема рейса в заказе или в выезде: видно, кто где сидит и оплачен ли. Можно пересадить туриста, заблокировать место под гида/сотрудника, снять неоплаченную бронь (решение за вами — система сама места не освобождает). Кнопка «Посадочная ведомость» — печать.
